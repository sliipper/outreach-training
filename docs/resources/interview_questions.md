# Interview question bank
This page contains a bank of questions that can be used when filming interviews for our social media. Try to balance physics and operation.

- "What is it that you have measured?"
- "Why is this measurement important?"
- "What have we learned that we did not understand before?"
- "Why is the LHCb detector useful for measuring this?"
- "What's next?"
- "How were you able to measure this?"
- "What are the important ingredients for making this measurement?"
- "How does X work?"
- "Why was X designed this way?"
